# Legacy Password Rotation

This note is deprecated and kept only for history. Do not follow it; see [Credential Exposure](/soc/credential-exposure.md) instead.[^current-guidance]

## Old 30-Day Rotation Rule

This outdated rule once required forcing every password to change every 30 days regardless of compromise signals.
That approach is no longer recommended: it pushes users toward weak, predictable passwords.
It conflicts with the current guidance to rotate only on suspected compromise.
