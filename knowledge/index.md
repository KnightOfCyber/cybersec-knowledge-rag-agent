# Knowledge Bundle

OKF v0.2 bundle of illustrative cybersecurity guidance for training use.

# SOC Investigation

* [Suspicious Login Detection](soc/suspicious-login-detection.md) - Illustrative guidance for recognizing suspicious authentication activity such as impossible travel and credential stuffing.
* [Authentication Log Sources](soc/auth-log-sources.md) - Illustrative reference of where authentication events live on common platforms.
* [Endpoint Alert Evidence](soc/endpoint-alert-evidence.md) - Illustrative guidance on what endpoint telemetry to collect for a login investigation.
* [Account Compromise Investigation](soc/account-compromise-investigation.md) - Illustrative step-by-step playbook for investigating a possibly compromised account.
* [Credential Exposure](soc/credential-exposure.md) - Illustrative guidance for handling exposed passwords and tokens during an investigation.
* [Incident Escalation](soc/incident-escalation.md) - Illustrative criteria and steps for escalating a login investigation to incident response.
* [Legacy Password Rotation](soc/legacy-password-rotation.md) - Deprecated illustrative note that once recommended forced 30-day password rotation.
* [Proposed EDR Query Draft](soc/proposed-edr-query.md) - Draft illustrative sketch of an EDR query for login correlation, not yet reviewed.

# General Cybersecurity

* [Network Security Basics](cybersecurity/network-security.md) - Illustrative defensive guidance for securing local networks, firewalls, and detecting port scans.
* [Secret Detection and Handling](cybersecurity/secret-detection.md) - Illustrative guidance for detecting leaked API keys and responding safely.
* [Linux Security Essentials](cybersecurity/linux-security.md) - Illustrative hardening steps for personal and small-team Linux systems.
* [Web Security Fundamentals](cybersecurity/web-security.md) - Illustrative defensive practices against XSS, SQL injection, and insecure authentication.
* [SOC Alert Triage](cybersecurity/soc-alerts.md) - Draft illustrative triage steps for common SOC alerts including phishing and malware.
